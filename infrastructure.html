Personal Website Infrastructure

Overview

This website is hosted on a cloud-based Linux VPS that I configured and manage myself. The goal of this project was to move away from static GitHub Pages hosting and build a self-managed hosting environment that provides greater flexibility, control, and opportunities to expand into dynamic web applications and backend services.

The project provided hands-on experience with Linux system administration, DNS management, web server configuration, SSL/TLS implementation, Git-based deployments, and cloud infrastructure management.

Motivation

GitHub Pages was sufficient for serving static content but did not support server-side technologies such as PHP or future backend functionality. To gain greater control over the hosting environment and create a platform capable of supporting future projects, I migrated the website to a self-managed Linux VPS.

The objective was not only to host a personal website, but also to build and maintain the underlying infrastructure myself.

  • Cloudflare DNS and Proxy Services
  • Hetzner Cloud VPS
  • Ubuntu Linux
  • Nginx Web Server
  • PHP-FPM
  • Let's Encrypt SSL/TLS Certificates
  • Git and GitHub Source Control
  • SSH Key Authentication

Security
  • HTTPS enabled using Cloudflare Full (Strict) SSL
  • SSH key-based authentication for server access
  • Restricted root account access
  • UFW firewall configured to allow only required services
  • Public website separated from future administrative functionality
  • Automatic SSL certificate renewal

Challenges
  • Migrating DNS management from Squarespace/Google Domains to Cloudflare
  • Configuring Nginx virtual hosts and site routing
  • Troubleshooting PHP-FPM integration and version compatibility
  • Resolving SSL/TLS configuration issues between Cloudflare and the VPS
  • Implementing HTTPS using Let's Encrypt certificates
  • Deploying website content from GitHub to a production Linux server
  • Configuring secure remote administration using SSH keys

Results

Key outcomes include:

  • Implemented end-to-end HTTPS encryption
