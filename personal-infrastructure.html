Overview

This project documents the design, deployment, and ongoing administration of my personal portfolio website. The objective was to move away from static GitHub Pages hosting and create a self-managed hosting environment capable of supporting dynamic web applications, future backend services, and long-term infrastructure growth.

The project provided practical experience with Linux server administration, DNS management, web server configuration, SSL/TLS implementation, Git-based deployments, and cloud infrastructure management.

Responsibilities & Accomplishments

  • Migrated domain management to Cloudflare.
  • Deployed and configured a Hetzner Cloud VPS.
  • Installed and configured Ubuntu Server.
  • Installed and configured Nginx web server.
  • Configured PHP-FPM support for dynamic content.
  • Implemented HTTPS using SSL/TLS certificates.
  • Configured Cloudflare Full (Strict) SSL mode.
  • Implemented SSH key-based authentication.
  • Configured UFW firewall policies.
  • Established GitHub-based deployment workflow.
  • Implemented automated backups and monitoring.
  • Performed performance optimization and security hardening.
  • Continue maintaining and expanding the platform.

Challenges

  • Migrating DNS management between providers.
  • Configuring Cloudflare proxy and SSL/TLS settings.
  • Troubleshooting certificate and HTTPS issues.
  • Configuring Nginx virtual hosts and routing.
  • Integrating PHP-FPM with Nginx.
  • Implementing secure remote administration using SSH keys.
  • Managing Linux file permissions and ownership.
  • Establishing a repeatable Git-based deployment process.
  • Resolving browser and CDN caching issues.

Lessons Learned

  • Linux system administration.
  • DNS management and troubleshooting.
  • Cloud-hosted infrastructure deployment.

  • Structured troubleshooting methodologies.
  • Infrastructure hardening and maintenance.

Results

Successfully migrated from static GitHub Pages hosting to a self-managed Linux VPS environment capable of supporting dynamic web applications and future infrastructure growth.

Established a secure, scalable, and maintainable platform while gaining practical experience with Linux administration, cloud infrastructure, web hosting, DNS, SSL/TLS, and deployment workflows.
